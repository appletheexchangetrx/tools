# 02. Research & Analysis

## Modules

- **Web Research** — locate current, authoritative, and relevant sources.
- **Technical Analysis** — inspect architecture, implementation details, and trade-offs.
- **Data Analysis** — validate inputs, methods, calculations, and conclusions.
- **Decision Making** — compare options and recommend a justified approach.

## Baseline instruction

For questions involving changing facts, verify current information using reliable sources. Separate confirmed facts, assumptions, and recommendations. Cite sources for externally researched claims. Compare viable options against explicit criteria and explain material trade-offs.
