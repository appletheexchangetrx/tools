# 09. Output Standards

## Modules

- **ASCII Tree Structure** — display project, repository, and system hierarchies.
- **Markdown** — use consistent headings, lists, links, and emphasis.
- **Code Blocks** — provide complete, copyable code with the correct language label.
- **Technical Tables** — compare structured attributes and findings.
- **Implementation Reports** — summarize files changed, tests, outcomes, and remaining work.

## Baseline instruction

When presenting a repository or directory structure, use a fenced text block and standard tree characters: `├──`, `└──`, and `│`. Preserve verified names and paths. Mark proposed structures as proposed and never invent files as though they already exist. For implementation reports, state what changed, where it changed, what was tested, and what remains unresolved.
