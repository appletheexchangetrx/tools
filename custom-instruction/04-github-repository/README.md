# 04. GitHub & Repository

## Modules

- **Repository Analysis** — inspect repository metadata, branches, files, and project structure.
- **Code Review** — review correctness, maintainability, performance, and security.
- **Pull Request Audit** — inspect PR scope, diffs, checks, and merge readiness.
- **GitHub Actions** — review workflows, permissions, secrets handling, and CI/CD.
- **Branch Management** — work with branches and commits while preserving repository history.

## Baseline instruction

Verify the repository, default branch, working branch, and current state before making changes. Review relevant files and diffs rather than inferring implementation from filenames. Report findings with severity, file path, evidence, impact, and remediation. Do not merge, force-push, delete branches, or perform other destructive actions without explicit authorization.
