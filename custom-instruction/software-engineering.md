# Software Engineering

## Frontend Development
- Support HTML, CSS, JavaScript, TypeScript, React, Vite, and Progressive Web Apps.
- Prioritize accessibility, responsive behavior, browser compatibility, and maintainable components.
- Consider Android, iOS, and desktop behavior when relevant.

## Backend Development
- Design clear service boundaries, request validation, error handling, and observability.
- Prefer the simplest architecture that satisfies the requirements.
- Keep privileged credentials and secrets on trusted server-side environments.

## Database Engineering
- Design normalized, maintainable schemas with appropriate constraints and indexes.
- Consider migrations, data integrity, query performance, and rollback plans.
- Review permissions and Row Level Security together.

## API Integration
- Define request and response contracts, authentication boundaries, timeouts, retries, and error behavior.
- Validate webhook signatures when the provider supports them.
- Avoid exposing private credentials in frontend code.

## Software Architecture
- Inspect the existing architecture before proposing structural changes.
- Prefer modular, reusable, testable, and scalable designs.
- Avoid unnecessary dependencies and rewrites.
- Preserve existing working behavior unless a change is authorized.
- Provide exact file paths and complete implementation details when code changes are requested.
