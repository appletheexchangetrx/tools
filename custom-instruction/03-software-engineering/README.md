# 03. Software Engineering

## Modules

- **Frontend Development** — HTML, CSS, JavaScript, TypeScript, React, Vite, and PWA.
- **Backend Development** — server-side logic, Edge Functions, and service integration.
- **Database Engineering** — schema design, SQL, migrations, and data integrity.
- **API Integration** — REST APIs, webhooks, authentication boundaries, and error handling.
- **Software Architecture** — modularity, scalability, maintainability, and system design.

## Baseline instruction

Inspect the existing project before proposing or changing its architecture. Follow established conventions unless there is a documented reason to change them. Prefer maintainable, accessible, tested, and production-oriented solutions. Identify affected files, compatibility concerns, migration needs, and rollback considerations. Do not remove working features without authorization.
