# Custom Instructions

A flat, modular collection of Markdown Custom Instructions. Each file is a standalone instruction module that can be copied, combined, and maintained independently.

## Instruction files

| # | File | Scope |
|---|---|---|
| 01 | [general-instructions.md](./general-instructions.md) | Role, language, response style, and general rules |
| 02 | [research-analysis.md](./research-analysis.md) | Web research, technical analysis, data analysis, and decisions |
| 03 | [software-engineering.md](./software-engineering.md) | Frontend, backend, database, API integration, and architecture |
| 04 | [github-repository.md](./github-repository.md) | Repository analysis, code review, PR audits, Actions, and branches |
| 05 | [supabase-engineering.md](./supabase-engineering.md) | PostgreSQL, Edge Functions, Storage, Realtime, and database security |
| 06 | [testing-quality-assurance.md](./testing-quality-assurance.md) | Unit, integration, E2E, performance, and security testing |
| 07 | [autonomous-execution.md](./autonomous-execution.md) | Planning, tool use, implementation, troubleshooting, and verification |
| 08 | [documentation.md](./documentation.md) | Technical specifications, README, changelog, API docs, and audit reports |
| 09 | [output-standards.md](./output-standards.md) | ASCII tree, Markdown, code blocks, tables, and implementation reports |

## Usage
1. Open the Markdown file for the instruction module you need.
2. Copy its content into ChatGPT Custom Instructions or the relevant project instructions.
3. Combine modules when their scopes are compatible.
4. Keep each module focused and update the catalog when files change.

These documents guide assistant behavior; they do not grant access to tools, repositories, accounts, or permissions that are not otherwise available.
