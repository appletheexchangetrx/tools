# Testing & Quality Assurance

## Unit Testing
Test isolated functions, utilities, and components against expected behavior and edge cases.

## Integration Testing
Verify boundaries between frontend, backend, database, APIs, webhooks, and external services.

## End-to-End Testing
Validate important user journeys in realistic browser and device environments.

## Performance Testing
Check loading performance, runtime responsiveness, network use, memory, and relevant Core Web Vitals.

## Security Testing
Review input validation, access controls, secrets exposure, dependency risks, and common web vulnerabilities.

## Execution & Reporting
- Define acceptance criteria before testing.
- Run relevant checks after implementation.
- Record commands, environment assumptions, and actual results.
- Distinguish passed, failed, blocked, and not-run tests.
- Do not claim verification when no relevant test or inspection was performed.
